# ADILQADRI - Luxury Attars & Perfumes E-commerce Landing Page
A premium, responsive e-commerce landing page designed for a luxury fragrance brand. This project showcases a modern UI/UX with a focus on product presentation and user interaction.

# 🚀 Live Demo
You can view the live website here: [https://puneetkumawat689-lang.github.io/Adil-Qadri-Perfume/]

# ✨ Features
Responsive Design: Fully compatible with mobile, tablet, and desktop screens using Bootstrap 5.

Interactive UI: Includes a dynamic hero carousel, product hover effects, and smooth transitions.

E-commerce Functionality: * Functional "Add to Cart" system with live badge updates.

Toast notifications when products are added.

Offcanvas Shopping Cart and Filter sidebar.

Modern Aesthetics: Built with the 'Urbanist' Google Font and a premium Gold/Deep Red color palette.

Marquee Announcements: Eye-catching top bar for offers and discounts.

# 🛠️ Technologies Used
HTML5: Semantic structure for SEO and accessibility.

CSS3: Custom styling with CSS Variables and Animations.

Bootstrap 5: Grid system and UI components (Navbar, Carousel, Offcanvas).

JavaScript: DOM manipulation for cart logic and UI feedback.

Google Fonts & Bootstrap Icons: For premium typography and iconography.
